📋 Operational Security Protocols: Do's vs. Don'ts

Adopt these gold-standard habits to reduce attack surfaces across all communication channels.

🔑 Authentication & Credentials

Identity
✅ ALWAYS DO:
  • Use 4-word random passphrases (e.g., Falcon#Crimson!River*99)
  • Store credentials in Bitwarden, 1Password, or company vault
  • Reject any unexpected MFA push notifications immediately
❌ NEVER DO:
  • Never write passwords on sticky notes or plain text files
  • Never share credentials over Slack, email, or WhatsApp
  • Never reuse personal email passwords on work accounts

📧 Inbound Communications

Messaging
✅ ALWAYS DO:
  • Inspect sender domain letter-by-letter for subtle typos
  • Verify wire or banking requests via official phone directory
  • Report suspicious messages to the Security Operations team
❌ NEVER DO:
  • Never click "Enable Content/Macros" on unexpected Word/Excel docs
  • Never read one-time SMS verification codes to callers
  • Never bypass warnings for invalid SSL/TLS website certificates

💻 Workstation & Mobility

Hardware
✅ ALWAYS DO:
  • Lock your screen every time you stand up from your workstation
  • Ensure full-disk encryption (BitLocker / FileVault) is active
  • Install operating system security updates promptly
❌ NEVER DO:
  • Never plug mysterious USB thumb drives found in parking lots
  • Never leave laptops unattended in vehicles or cafe tables
  • Never disable corporate Endpoint Detection & Response (EDR)

🌐 Wireless & Travel Hygiene

Network
✅ ALWAYS DO:
  • Turn on enterprise VPN prior to connecting on hotel/airport Wi-Fi
  • Use mobile hotspot tethering for highly confidential transactions
  • Verify padlock icon and strict HTTPS on all destinations
❌ NEVER DO:
  • Never connect to unencrypted Wi-Fi networks without VPN active
  • Never leave Bluetooth set to 'Discoverable' in crowded venues
  • Never ignore browser warnings about altered certificates
